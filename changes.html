WHAT CHANGED

This fork of find3r

find3r is Snowfro's onchain file browser; the original is at find3r.app. This copy started from find3r's files exactly as published onchain (BAMFS on Base Sepolia, version 5) and changes the things listed below. The full diff against that untouched copy is on GitHub: upstream...main.

ENS names that work

find3r looked names up in the ENS v1 registry, so names on ENS v2 (live on mainnet since October 27, 2026) and names served offchain failed with "no direct onchain resolver". This fork asks the ENS Universal Resolver instead, which answers for v1, v2 and offchain names (CCIP-Read, EIP-3668). For example, thebenmeadows.eth and nick.eth gave that error in the original and resolve in this fork. Commit

Any ENS name in Go to

The address box took only names ending in .eth. It now takes any ENS name, so names like name.cb.id work too. Commit

Wallets load about 3x faster

Outside find3r.app, the reader waited 250 ms between RPC requests and re-read each chain's id and block number on every request. Both are gone: requests run 6 at a time, a rate-limited request is retried, and one block is pinned per chain for a page load. A wallet that took 15.4 s and 129 requests to load now takes about 5 s and 113 requests (headless Chromium, all chains, three runs). Commit

Names next to addresses

An opened wallet and an artwork's owner and artist show the address's ENS primary name, for example "0x98f1bd…14934 · thebenmeadows.eth". A name is shown only if it points back to the same address. Lookups use the Ethereum connection from Settings when you have set one. Contract addresses never get a name. Commit. Settings has a switch, "Show ENS names next to addresses", on by default; off removes the labels and stops the lookups, while a name typed into the address box still resolves. Commit

Remembered collection types are re-checked

Whether a contract is an ERC-721 or ERC-1155 collection, and its ABX version, is remembered on this device for 30 days so a folder does not re-ask the chain for every collection. Before a remembered answer is used, this fork re-reads those three facts for every remembered contract in one Multicall3 call at the pinned block; an answer that changed (an upgraded proxy, for example) is forgotten and read live again. If that check cannot run, the remembered answers are not used for that load. Commit

What leaves the browser

Beyond what find3r already sent (chain reads to the RPCs, collection lookups to resolver.abx.io and data.artblocks.io), this fork sends: the addresses it labels with names to the Ethereum RPC (from Settings, else ethereum-rpc.publicnode.com), and for offchain names the lookup to that name's gateway (api.coinbase.com, ccip-v3.ens.xyz or dnssec-oracle.ens.domains); one request per wallet view for the ABX owner index at abx.thebenmeadows.com, which carries no wallet address; and early connections to those hosts when a page opens. ABX holdings come from that index, which is rebuilt every 15 minutes and can run about an hour behind; the folder says how old it is.

The thebenmeadows.com look, light and dark

Colors, type (Public Sans) and the flat style of thebenmeadows.com, with a dark theme that follows your system setting and a Light/Dark button in the header that remembers your choice. Commit

Readable source

find3r ships minified bundles. The first commit after the untouched copy only reformats them (Prettier), so every change above is a readable diff. Commit
